# Profile: Zimbabwe (ZLITS)

The Zimbabwe national instance of the LITS standard. This folder holds the **open** national
parameters; the running registry and its operations are held privately by the operator.

| Parameter | Value |
|---|---|
| Instance name | ZLITS (working name; ratified with DVS) |
| Country code | `zw` |
| Sovereign domain | a `*.gov.zw` host (mapped on designation) |
| Scope | cattle first, extensible to small stock |
| `national_id` scheme | to be ratified with the Department of Veterinary Services (DVS) |

- **Legal basis & nationalization pathway:** [legal-basis-and-mandate.md](./legal-basis-and-mandate.md)
  — the Animal Health Act [Chapter 19:01], the Cyber & Data Protection Act [Chapter 12:07]
  (POTRAZ), and the designating Statutory Instrument.
- Veterinary-zone reference data and the official acronym / numbering scheme are added here as
  they are ratified.

> Status: draft profile — names, domains and the numbering scheme are not finalised.
